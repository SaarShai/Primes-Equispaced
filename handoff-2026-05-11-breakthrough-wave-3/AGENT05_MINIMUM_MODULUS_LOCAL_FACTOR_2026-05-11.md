# Agent 05 Minimum-Modulus Local Factor Route

status: `NO_GO`

## Verdict

The local factor route does not independently prove the rank-one H1 budget.

For a simple zero `rho=1+i gamma`, write

```text
L(E,s)=(s-rho)g_rho(s),    g_rho(rho)=L'(E,rho).
```

A zero-free circle is useful only after a quantitative boundary lower bound.
If

```text
|s-rho|=r_T is zero-free except for rho inside,
min_(|s-rho|=r_T) |L(E,s)| >= m_T,
```

then

```text
|L'(E,rho)| >= m_T/r_T.
```

This is exact, but it is not generated by zero-freeness, Jensen, Cartan,
Hadamard products, or subharmonicity alone. Those tools either restate the
missing lower bound for `g_rho(rho)` or give lower bounds away from exceptional
sets, not on every zero-centered boundary needed for H1.

## Exact Exponent

Write the local certificate as

```text
r_T = T^(-kappa) (log T)^(-b),
m_T = T^(-mu)    (log T)^(-B).
```

Then

```text
|L'(E,rho)| >= T^(-(mu-kappa)) (log T)^(b-B).
```

Set

```text
alpha = mu-kappa,
lambda = b-B.
```

Using the EC zero count `N_E(T,2T) <<_E T log T`,

```text
R_E,1(T)
  <= T log T * T^alpha (log T)^(-lambda)
  = T^(1+alpha) (log T)^(1-lambda).
```

Therefore the local route beats the rank-one H1 threshold

```text
R_E,1(T)=o(T^2)
```

exactly in the following cases:

```text
alpha < 1,
```

or

```text
alpha = 1 and lambda > 1.
```

Equivalently, the required pointwise lower bound is

```text
|L'(E,rho)| >= h(T) log T / T,    h(T)->infinity.
```

If `r_T ~ 1/log T`, this requires

```text
min_(|s-rho|=r_T) |L(E,s)| >= h(T)/T.
```

The borderline bound `m_T/r_T ~ log T/T` gives only `R_E,1(T)=O(T^2)`,
not `o(T^2)`.

## Local Proof

Assume `L(E,s)` is analytic in `|s-rho|<=r` and has no zero in the punctured
disk. Then `g_rho` is holomorphic and nonvanishing in the disk. On the boundary,

```text
|g_rho(s)|=|L(E,s)|/r >= m/r.
```

Since `1/g_rho` is holomorphic, the maximum principle gives

```text
|1/g_rho(rho)| <= r/m.
```

Thus

```text
|L'(E,rho)|=|g_rho(rho)| >= m/r.
```

This proves the exponent table above. It also shows the obstruction: all
strength is in `m`, not in zero-freeness.

## Why The Standard Routes Do Not Supply `m`

### Zero-Free Circle Alone

A punctured zero-free disk only says `g_rho` has no zeros. It gives no lower
bound for `g_rho(rho)`. The model function

```text
f_epsilon(s)=epsilon (s-rho)
```

has the same local zero geometry for every `epsilon>0`, but

```text
f_epsilon'(rho)=epsilon.
```

For the actual EC `L`-function the normalization is fixed, but this shows why
zero geometry alone cannot prove a power lower bound.

### Jensen / Subharmonicity

For nonvanishing `g_rho`,

```text
log |g_rho(rho)|
```

is the boundary average of `log |g_rho|` on any zero-free circle. A lower bound
for that average is already a lower bound for `|L'(rho)|`; Jensen does not
create it. A lower bound at one boundary point, or outside a small exceptional
set, is insufficient for the maximum-principle argument.

### Cartan

Cartan-type lower bounds remove small disks around zeros or produce good
points. H1 needs every zero-centered circle, or a bad-set reciprocal budget.
If a Cartan exceptional disk intersects the required circle near its minimum,
the local derivative remains uncontrolled. Count-only control of exceptional
circles does not imply

```text
sum_(bad rho) |L'(E,rho)|^(-1)=o(T^2).
```

### Hadamard Products

A Hadamard product expresses `L'(rho)` through the exponential factor and all
other zeros. A close neighbor creates an explicit small factor, while many
moderately close zeros can also depress the product. Lower-bounding the product
requires exactly the missing reciprocal-derivative or small-gap-plus-cap input.
The product representation is bookkeeping, not an H1 proof.

## Carry-Forward Theorem If This Route Is Revived

The only useful revival is the explicit local theorem:

```text
H1-LocalMinMod(E):
For all simple zeros rho=1+i gamma in T<|gamma|<=2T outside B_T, there is a
zero-free circle |s-rho|=r_rho such that

  min_(|s-rho|=r_rho) |L(E,s)|
    >= r_rho h(T) log T / T,    h(T)->infinity,

  sum_(rho in B_T) |L'(E,rho)|^(-1)=o(T^2).
```

Then `R_E,1(T)=o(T^2)` for analytic rank one. Without the bad reciprocal
budget, this remains a restatement of the H1 obstruction.
